# CREED Neurov Framework — Homepage

A responsive static homepage prototype for CREED.

## Publish on GitHub Pages
1. Upload the contents of this folder into the root of your `creed-neurov-framework` repository.
2. Make sure `index.html` is at the repository root (not inside another folder).
3. In Settings → Pages, select Deploy from a branch, `main`, and `/ (root)`.
4. Save and wait for GitHub Pages to publish.

## Notes
- This is an initial visual prototype. The navigation sections are front-end anchors.
- CREED AI, Campus, accounts, quizzes, and library functionality are concepts for later development.
- The contact link currently uses a placeholder address (`hello@creed.example`); replace it before launch.
- Fonts load from Google Fonts when internet access is available; system fallbacks are included.
